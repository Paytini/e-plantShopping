# e-plantShopping - Paradise Nursery

**Paradise Nursery** (`e-plantShopping`) is a React and Redux shopping cart application for an online houseplant store.

## Features
* Browse a categorized catalog of houseplants (Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, and Low Maintenance).
* Add plants to the shopping cart with real-time state management using Redux Toolkit.
* View a dynamic cart badge showing the total number of items.
* Increment, decrement, or remove items directly from the cart with live subtotal and total cost calculations.
